# Тестирование программного обеспечения (ИТМО, 3 курс)

Комплекс лабораторных работ по дисциплине «Тестирование программного обеспечения» (ТПО). Программа охватывает полный спектр обеспечения качества ПО: от изоляционного модульного тестирования до интеграционной верификации, автоматизации E2E и нагрузочного стресс-тестирования.

---

## 🗂 Структура лабораторных работ

| Лабораторная | Методология и стек | Описание и охват |
| :--- | :--- | :--- |
| [**Лабораторная №1**](./lab1) | **Модульное тестирование (Unit Testing)**<br>`JUnit 5`, `Mockito` | Изолированное тестирование трех независимых модулей: математическая функция (ряд Тейлора), алгоритм/структура данных (хэш-таблица с открытой адресацией) и поведение доменной модели. |
| [**Лабораторная №2**](./lab2) | **Интеграционное тестирование функций**<br>`JUnit 5`, `Mockito`, `CSV Export` | Тестирование сложной математической системы, построенной на суперпозиции тригонометрических (`sin`, `cos`, `tan`, `cot`, `sec`, `csc`) и логарифмических (`ln`, `log_2`, `log_3`, `log_5`, `log_10`) функций. Мокирование зависимостей снизу вверх. |
| [**Лабораторная №4**](./lab4) | **Нагрузочное и стресс-тестирование**<br>`Apache JMeter`, `JMX Test Plans`, `Python (Matplotlib)` | Разработка сценариев нагрузки (Thread Groups), профилирование устойчивости под пиковой нагрузкой, замеры Throughput и Latency, проверка Response Assertions, построение аналитических графиков. |

---

## 🛠 Технический стек

* **Тестовые фреймворки:** JUnit 5 (Jupiter), Mockito, AssertJ
* **Нагрузочное тестирование:** Apache JMeter (JMX-планы тестирования, JTL-логи)
* **Анализ результатов:** Python (Matplotlib) для визуализации пропускной способности
* **Сборка:** Apache Maven
