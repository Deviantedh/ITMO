# Компьютерные сети (ИТМО, 3 курс)

Лабораторные работы по архитектуре, моделированию и протоколам стека TCP/IP в корпоративных и локальных вычислительных сетях.

---

## 🗂 Структура лабораторных работ

| Лабораторная | Инструменты | Содержание |
| :--- | :--- | :--- |
| [**Лабораторная №1**](./lab1) | `NetEmul`, `CIDR` | Проектирование топологии локальной сети, расчет IP-адресации, масок подсетей и шлюзов по умолчанию. |
| [**Лабораторная №2**](./lab2) | `NetEmul`, `Switching` | Коммутация канального уровня: работа MAC-таблиц коммутаторов, широковещательные домены, ARP-протокол. |
| [**Лабораторная №3**](./lab3) | `NetEmul`, `Routing` | Маршрутизация сетевого уровня: статическая маршрутизация, динамический протокол RIP, автоматическая конфигурация DHCP. |
| [**Лабораторная №4**](./lab4) | `Wireshark`, `Python` | Анализ сетевого трафика на транспортном и прикладном уровнях: трехстороннее рукопожатие TCP (SYN/ACK), скользящее окно, разбор протоколов DNS и HTTP в Wireshark. |

---

## 🛠 Технический стек

* **Симуляторы сетей:** NetEmul
* **Анализ трафика:** Wireshark (`.pcap` / `.pcapng` трассировки)
* **Протоколы:** Ethernet, ARP, IPv4, ICMP, TCP, UDP, DHCP, RIP, DNS, HTTP
