# Имитационное моделирование систем (ИТМО, 3 курс)

Расчетно-графические и лабораторные работы по имитационному моделированию систем массового обслуживания (СМО).

---

## 🗂 Содержание

* **Стохастическое моделирование на GPSS World (`.gps`):** построение многоканальных СМО с очередями, моделирование распределений Пуассона и экспоненциальных потоков заявок.
* **Анализ характеристик систем:** оценка среднего времени ожидания в очереди, коэффициентов загрузки обслуживающих приборов и вероятности отказа в обслуживании.
* **Статистическая обработка результатов:** расчет доверительных интервалов и проверка статистических гипотез адекватности модели.
