## Пиксель

Для пикселя `image[2428, 3688]`, где `2428` - строка, `3688` - столбец:

- `R = 165`
- `G = 62`
- `B = 92`

Примечание: OpenCV читает изображение в порядке каналов `BGR`, поэтому значение из `cv2.imread(...)[2428, 3688]` равно `[92, 62, 165]`, а в форме нужны `R, G, B`.
