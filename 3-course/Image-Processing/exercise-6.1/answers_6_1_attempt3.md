# Упражнение 6.1, попытка 3

Источник: `karsten-winegeart-qzCgm273HW0-unsplash.jpg`

1. Исходная ширина / высота: `0.668`
2. Высота сжатого изображения при ширине `1372`: `2054`
3. Максимальная плотность по RGB-каналам: `0.0602`
4. После линейной нормировки RGB для пикселя `[1032, 678]` по строгому тексту задания:
   - R: `222` — не подошло
   - G: `216`
   - B: `207` — не подошло
5. Количество коэффициентов `|cA1| < 120`: `8088`

Следующий самый вероятный вариант: тест ожидает порядок OpenCV BGR, несмотря на текст про RGB:
   - R: `207`
   - G: `216`
   - B: `222`

Если это не пройдет, для R стоит пробовать подсказки расширения: `232`, потом `221`. Для B ближайшие расчетные кандидаты: `206`, `205`, `222`.

Примечание: для первого варианта использовалась 0-based индексация `[row, col]` и нормировка каждого RGB-канала через `cv2.normalize(..., 0, 255, cv2.NORM_MINMAX)`.
