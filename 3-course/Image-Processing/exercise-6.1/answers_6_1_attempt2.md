# Ответы для зачетного задания 6.1, попытка 2

Исходное изображение: `input_images/ian-schneider-PAykYb-8Er8-unsplash.jpg`

## Ответы для формы

- Коэффициент отношения исходной ширины к высоте: `1.498`
- Высота полученного сжатого изображения: `1776`
- Наибольшее значение плотности среди RGB-каналов: `0.3832`
- Интенсивность канала `R`: `82`
- Интенсивность канала `G`: `61`
- Интенсивность канала `B`: `38`
- Количество коэффициентов `|cA1| < 40`: `0`

## Проверка

```text
5322 / 3553 = 1.4978891077962286 -> 1.498
floor(2661 / 1.4978891077962286) = 1776
```

RGB после линейной нормировки для `normalized_rgb[914, 1291]`:

```text
[82, 61, 38]
```

Если LMS трактует строку и столбец как 1-based координаты, альтернативный пиксель `normalized_rgb[913, 1290]`:

```text
[154, 134, 105]
```

Но в предыдущих заданиях подход с прямым матричным индексом был 0-based, поэтому основной ответ: `82, 61, 38`.
