## Примечания

Коэффициент:

```text
5717 / 4672 = 1.2236729452054795 -> 1.224
floor(2858 / 1.2236729452054795) = 2335
```

Плотность считалась через:

```python
np.histogram(channel.ravel(), bins=256, range=(0, 256), density=True)
```

Для Haar-преобразования после линейной нормировки RGB-изображение переведено в grayscale:

```python
normalized_gray = cv2.cvtColor(normalized_rgb, cv2.COLOR_RGB2GRAY)
cA, _ = pywt.dwt2(normalized_gray, 'haar')
cA1, _ = pywt.dwt2(cA, 'haar')
count = np.sum(np.abs(cA1) < 60)
```

Если LMS ожидала Haar по каждому RGB-каналу отдельно, альтернативное количество будет `307820`. Если применить `pywt.dwt2` напрямую к RGB-массиву с параметрами по умолчанию, получается `275887`.
