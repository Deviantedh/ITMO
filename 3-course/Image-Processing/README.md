# Обработка изображений и компьютерное зрение (ИТМО, 3 курс)

Практические работы по методам цифровой обработки изображений, пространственной фильтрации и глубокому обучению в компьютерном зрении.

---

## 🗂 Содержание

* **exercise-1:** Детекция объектов в реальном времени с использованием архитектуры **YOLOv11** (PyTorch / Ultralytics).
* **exercise-2:** Пространственная фильтрация изображений, выравнивание гистограмм, сглаживание и повышение резкости средствами OpenCV.
* **exercise-3:** Пороговая бинаризация, морфологические операции (эрозия, дилатация, открытие, закрытие).
* **exercise-4 & 5:** Выделение границ и контуров (операторы Собеля, Лапласа, детектор границ Кэнни).
* **exercise-6:** Анализ геометрических признаков объектов и сегментация областей.

---

## 🛠 Технический стек

* **Среда:** Python 3, Jupyter Notebooks
* **Библиотеки:** OpenCV, PyTorch, Ultralytics YOLO, NumPy, Matplotlib
