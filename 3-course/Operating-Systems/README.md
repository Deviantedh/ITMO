# Операционные системы (ИТМО, 3 курс)

Лабораторный практикум по системному программированию в среде Linux с использованием POSIX API на C и C++.

---

## 🗂 Содержание

* **Системные вызовы и управление процессами:** порождение процессов (`fork()`, семейство `exec()`, `waitpid()`), обработка зомби-процессов и сирот.
* **Межпроцессное взаимодействие (IPC):** анонимные и именованные каналы (pipe / FIFO), разделяемая память (POSIX shared memory), семафоры и очереди сообщений.
* **Многопоточность и синхронизация:** потоки POSIX (`pthread`), мьютексы, условные переменные (`pthread_cond`), предотвращение взаимных блокировок (deadlocks) и гонок данных (race conditions).
* **Управление памятью:** виртуальная память, динамическое выделение, защита страниц памяти (`mprotect()`, `mmap()`).
