# Технологии нейросетевых вычислений (ИТМО, 4 курс)

Практикум по глубокому обучению (Deep Learning) и компьютерному зрению на базе фреймворка **PyTorch**.

---

## 🗂 Содержание

* **Лабораторная работа №1 (`TNC_Lab1`):** Многослойный перцептрон (MLP), функции активации (ReLU, GELU, Sigmoid), оптимизаторы (SGD, AdamW), обратное распространение ошибки (Backpropagation).
* **Лабораторная работа №2 (`TNC_Lab2`):** Сверточные нейронные сети (CNN), операции свертки и пулинга, борьба с переобучением (Dropout, BatchNorm, аугментация данных).
* **Сегментация и детекция (`С10_CNN`):** Глубокие архитектуры **ResNet** и **U-Net** для попиксельной сегментации изображений и обнаружения объектов.
