# Проектирование встраиваемых систем (ИТМО, 4 курс)

Аппаратно-программный практикум по разработке прошивок и управляющего ПО для микропроцессорных систем на базе **STM32 (ARM Cortex-M)**.

---

## 🗂 Содержание

* **Управляющий GUI-клиент (`client_gui.py`):** десктопное приложение на Python для взаимодействия с лабораторным стендом STM32 через последовательный интерфейс (UART / Virtual COM Port).
* **Протокол обмена:** пакетная передача данных, валидация контрольных сумм, обработка команд реального времени.
* **Автоматизация отчетов (`generate_lab*_report.py`):** скрипты генерации и верификации лабораторных результатов.
* **Отчеты:** выполненные и защищенные лабораторные работы (ЛР 1–4).
