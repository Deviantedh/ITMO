# Программирование на Java (ИТМО, 1 курс)

Комплекс лабораторных работ по дисциплине «Программирование» (факультет ПИиКТ / ФИТиП, Университет ИТМО). Курс охватывает путь от фундаментального объектно-ориентированного программирования до распределенных многопоточных клиент-серверных систем с персистентностью в реляционных СУБД.

---

## 🗂 Структура лабораторных работ

| Лабораторная | Тематика и стек | Ключевые концепции и архитектура |
| :--- | :--- | :--- |
| [**Лабораторная №2**](./lab2) | **ООП и полиморфизм**<br>`Java Core`, `Pokemon SDK` | Иерархия классов, наследование, переопределение методов, полиморфизм поведения при атаках и статусных эффектах. |
| [**Лабораторная №3**](./lab3) | **Интерфейсы и доменная модель**<br>`Java Core` | Разработка контрактов (интерфейсов), абстрактных типов, переопределение методов `equals()`, `hashCode()`, `toString()`. |
| [**Лабораторная №4**](./lab4) | **Исключения и внутренние классы**<br>`Java Exceptions` | Обработка проверяемых (checked) и непроверяемых (unchecked) исключений, статические вложенные и анонимные классы. |
| [**Лабораторная №5**](./lab5) | **Коллекции и CLI управление**<br>`Java Collections`, `XML/JSON` | Паттерн **Command**, потокобезопасная работа с коллекцией объектов, валидация входных потоков, сериализация состояния в файл. |
| [**Лабораторная №6**](./lab6) | **Клиент-серверная архитектура**<br>`Java NIO`, `TCP/UDP Sockets` | Неблокирующий ввод-вывод (NIO Channels, Selectors), кастомный бинарный протокол сериализации команд и передачи объектов по сети. |
| [**Лабораторная №7**](./lab7) | **Базы данных и многопоточность**<br>`PostgreSQL`, `Concurrency`, `SHA-384` | Пул потоков (`ForkJoinPool`, `ExecutorService`), транзакционная работа с PostgreSQL via JDBC, хеширование паролей с солью, разграничение прав владения объектами. |

---

## 🛠 Технический стек

* **Язык:** Java 17+
* **Сетевое взаимодействие:** Java Sockets, Java NIO (Channel, Selector)
* **СУБД:** PostgreSQL, JDBC
* **Безопасность:** Хеширование паролей SHA-384 + Salt, сессионная аутентификация
* **Архитектурные паттерны:** Command, Factory, DAO, Client-Server, Strategy
